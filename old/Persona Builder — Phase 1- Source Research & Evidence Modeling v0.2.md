# PERSONA BUILDER — PHASE 1
## Source Research & Evidence Modeling
### v0.2 — Shared Artifact Grammar

---

# 0. PHASE CONTRACT

## PURPOSE

Collect, verify, organize, and calibrate evidence about the target character so that Phase 2 can construct an evidence-grounded Core Character Model.

Phase 1 answers:

> **What does the available source material actually give us to work with?**

Phase 1 does **not** construct the character model.

---

## INPUTS

Use when supplied:

- target character
- source material
- source URLs / files
- source / original language
- intended characterization scope
- relevant work / adaptation / continuity
- known source limitations

Optional:

- target RP language
- target relationship premise
- target deployment
- specific research questions
- user-supplied observations

Do not invent missing constraints.

---

## OUTPUTS

Produce these artifact classes in this order:

1. RESEARCH HEADER
2. SOURCE COMPILATION
3. EVIDENCE LEDGER

# 1. SHARED ARTIFACT GRAMMAR

This phase uses the shared Persona Builder artifact conventions.

## 1.1 SECTION RULE

A canonical section must appear in the specified order.

If it has no meaningful entries, leave it structurally present and write:

`NONE ESTABLISHED`

Do not invent content merely to populate the section.

## 1.2 ENTRY RULE

Entries are conditional.

Create an entry only when the source material provides materially useful information.

Do not create placeholder entries.

## 1.3 FIELD RULE

Fields are divided into:

- **REQUIRED** — necessary for the artifact to be meaningful
- **OPTIONAL** — include only when useful
- **FORBIDDEN** — must not be introduced into that artifact

Optional fields may be omitted.

## 1.4 OMISSION RULE

Do not fill an optional field with filler such as:

- none
- not applicable
- no evidence
- no counterevidence
- unknown

unless that condition itself is analytically relevant.

`Unknown` is used when uncertainty is meaningful.

Otherwise, omission is preferred.

## 1.5 ID RULE

Use zero-padded IDs.

Do not reuse IDs.

Do not invent references to nonexistent evidence.

## 1.6 EVIDENCE REFERENCE RULE

When an artifact refers to evidence, reference existing Phase 1 IDs exactly.

Do not create a new evidence ID merely to support an interpretation.

## 1.7 PROVENANCE RULE

Use only:

- DIRECT
- REPRODUCED
- SECONDARY
- INFERENCE
- SPECULATION

Do not silently upgrade provenance.

## 1.8 INTERPRETATION RULE

Phase 1 may include a brief interpretive note when it helps Phase 2.

It must not become a finished personality judgment.

# 2. GOVERNING PRINCIPLES

## 2.1 Evidence Before Characterization

Do not decide what the character is and then collect confirming evidence.

Research first.

Character modeling comes in Phase 2.

## 2.2 Observe Before Abstracting

Prefer:

> what happened

over:

> what it means.

For example:

Weak:

> The character is caring.

Better:

> When another character is struggling, she repeatedly notices the problem and takes practical action without being asked.

The second provides evidence from which Phase 2 may construct a mechanism.

## 2.3 Fixed Grammar, Variable Occupancy

The output structure must remain recognizable across characters.

The quantity and detail of entries may vary naturally.

## 2.4 Unknown Is Valid

Accept:

- insufficient evidence
- not observable
- conflicting evidence
- unclear provenance
- inaccessible source
- outside current scope

Do not manufacture certainty.

## 2.5 Salience Is Not Centrality

A famous line, iconic scene, meme, visual gag, dramatic failure, or heavily repeated summary is not automatically representative.

Seek recurrence, variation, and ordinary behavior.

## 2.6 One Example Is Not a Rule

A single observation can establish that something can occur.

It does not automatically establish:

- frequency
- centrality
- permanence
- typicality

Record scope where relevant.

## 2.7 Contradiction Is Evidence

Conflicting observations may reveal:

- context dependence
- relationship dependence
- development
- adaptation differences
- presentation effects
- an incorrect interpretation

Preserve conflicts instead of smoothing them away.

# 5. EVIDENCE LEDGER

This is the primary Phase 1 artifact.

## EVIDENCE LEDGER

### E001 — [SHORT DESCRIPTION]

### REQUIRED

- OBSERVATION:
- CONTEXT:
- EVIDENCE:
- PROVENANCE:

### OPTIONAL

- FREQUENCY:
- CHARACTER SCOPE:
- QUALIFIER:
- INTERPRETIVE NOTE:

### FIELD RULES

`OBSERVATION`

Describe the relevant behavior, speech, decision, reaction, or explicit characterization concretely.

`CONTEXT`

Include only context needed to interpret the observation.

`EVIDENCE`

Use a quotation, paraphrase, transcript reference, scene reference, or other recoverable support.

`PROVENANCE`

Use exactly one:

- DIRECT
- REPRODUCED
- SECONDARY
- INFERENCE
- SPECULATION

Phase 1 should normally rely on DIRECT, REPRODUCED, and SECONDARY evidence.

Use INFERENCE or SPECULATION only for explicitly marked research leads.

`FREQUENCY`

Only record when repetition is materially established.

Use qualitative descriptions such as:

- recurring
- occasional
- rare
- one observed instance
- unknown

Do not invent numerical frequencies.

`CHARACTER SCOPE`

Use only when necessary to distinguish:

- baseline
- situational
- relationship-specific
- version-specific
- developmental
- exceptional

`QUALIFIER`

Use for a limitation that materially changes interpretation.

`INTERPRETIVE NOTE`

Optional research guidance for Phase 2.

It must not become a finished character conclusion.

- LOW

- Which observations appear related?
- Which occur under similar conditions?
- Which conflict?

- Which are version-specific?
- Which concern presentation rather than behavior?

# 15. SEARCH STRATEGY

When external research is available, search for behavioral variation.

Useful directions include:

- ordinary conversation
- disagreement
- failure
- mistakes
- embarrassment
- conflict
- recovery
- friendship
- rivalry
- internal thoughts
- dialogue / transcripts
- development
- adaptation differences

Search for counterexamples deliberately.

Do not research only the character's most famous trait.

---

# 16. SOURCE-LANGUAGE RESEARCH

When reasonably accessible, prefer original-language evidence for original-language works.

For Japanese-origin material, investigate Japanese evidence where practical.

For other languages, apply the same principle.

Use translated or English-language material for:

- discovery
- cross-checking
- accessibility
- supplementary context

Do not allow a translation to overwrite original-language evidence when the original is available.

---

# 17. PRESENTATION VS CHARACTER EVIDENCE

Where the medium introduces presentation effects, distinguish:

- CHARACTER
- PRESENTATION
- MIXED
- UNKNOWN

Possible presentation effects include:

- comedic exaggeration
- editing
- reaction shots
- voice-performance emphasis
- gameplay repetition
- player control
- visual shorthand
- narrator framing
- localization
- adaptation compression

Do not discard presentation evidence automatically.

---

# 18. EXTERNAL / REAL-WORLD MATERIAL

When external source material is relevant, separate:

- external fact
- fictional source material
- fictional characterization
- later interpretation

External fact is not automatically character evidence.

# 21. HANDOFF RULE

Phase 1 passes **evidence**, not a rewritten character.

The canonical Phase 2 input is:

> SOURCE COMPILATION + EVIDENCE LEDGER + COVERAGE + CONFLICTS + SCOPE NOTES

Voice, relationship, and temporal/version evidence are supplied as specialized evidence views where relevant.

A brief interpretive note may help Phase 2 locate a research issue, but it is not authoritative characterization.

---

# 22. EXECUTION RULE

When executing Phase 1:

1. Read supplied source material first.
2. Record source access honestly.
3. Collect concrete evidence before abstracting traits.
4. Seek variation and counterevidence.
5. Preserve context.
6. Preserve contradictions.
7. Distinguish provenance.
8. Keep relationship-specific evidence scoped.
9. Keep voice evidence separate from target-language realization.
10. Record important gaps.
11. Do not manufacture entries to satisfy cardinality.
12. Do not construct the final persona.
13. Do not manufacture Core mechanisms.
14. Complete the audit.
15. Mark `READY FOR PHASE 2` only when the evidence base is reasonably usable.
