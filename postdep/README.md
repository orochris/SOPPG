# Post-SOPPG

A very rough idea for post-deployment character development analysis.

The basic thought is that, after a character has been deployed and actually used for a while, it may be useful to look back at the interaction and ask whether anything about the character has emerged that wasn't adequately captured in the original specification.

Something along the lines of:

**character prompt → deployment → interaction → retrospective analysis → optional prompt edit**

This is deliberately not part of the core SOPPG pipeline, and may or may not be useful in practice.

I imagine this kind of post-deployment prompt edit could be useful.

**Do whatever you like with it.**
